# AI engineering skills scorecard

Score each capability from 0 to 3:

- **0 — Unfamiliar:** cannot explain or implement it.
- **1 — Guided:** can complete it with a tutorial or substantial assistance.
- **2 — Independent:** can design, implement, test, and explain it alone.
- **3 — Production:** can handle edge cases, operations, tradeoffs, and mentor others.

Do not award a 2 or 3 without linking evidence.

## Quarterly review

Answer these with evidence:

1. What can I build now that I could not build three months ago?
2. Which failure class surprised me most?
3. Which metric changed an engineering decision?
4. Where am I relying on framework knowledge instead of first principles?
5. Which project most clearly demonstrates production judgment?
6. What capability is the bottleneck for my next target role?
